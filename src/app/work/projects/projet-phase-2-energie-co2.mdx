## Objectif

Predire deux cibles sur des batiments:

- `SiteEnergyUse(kBtu)` pour la consommation d'energie
- `TotalGHGEmissions` pour les emissions de CO2

## Contenu

- Trois notebooks de travail: exploration generale, modele energie, modele CO2
- Feature engineering et pretraitement pour variables numeriques et categorielles
- Artefacts finaux separes pour les deux modeles
- API FastAPI deployable avec endpoints de prediction `energy`, `co2` et `both`

## Resultats

- Energie: `R2 test = 0.852`
- CO2: `R2 test = 0.841`
- Gain net sur la baseline sur les deux cibles

## Outils

Python, pandas, scikit-learn, XGBoost, FastAPI, joblib.
