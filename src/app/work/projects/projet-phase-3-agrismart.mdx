## Objectif

Construire un prototype de detection de maladies des cultures a partir d'images de feuilles et comparer deux approches de deep learning.

## Contenu

- Notebook final `AgriSmart_DL.ipynb`
- CNN simple entraine depuis zero
- MobileNetV2 en transfer learning puis fine-tuning
- Modele final exporte en formats `.tflite` et `.keras`
- API FastAPI de demonstration
- Application mobile Expo pour la soutenance

## Architecture

- `notebooks/` pour l'experimentation et la comparaison des modeles
- `models/final/` pour les artefacts de production
- `backend/` pour l'inference API
- `mobile/` pour la demo mobile
- `docs/` pour le brief, la presentation et les guides de deploiement

## Outils

Python, TensorFlow, Keras, MobileNetV2, FastAPI, Expo React Native.
